3. ACTUALIZACIONES
------------------
3.1  Las actualizaciones del Software son opcionales. El usuario
     puede elegir instalarlas o no. Sin embargo, versiones muy
     antiguas pueden dejar de recibir soporte técnico.

3.2  Cada nueva versión puede incluir correcciones de errores,
     mejoras de rendimiento, nuevas funcionalidades o la
     eliminación o modificación de funcionalidades existentes.

3.3  Actualizaciones de versión menor (ej: v2.0 a v2.1):
       - Los datos del negocio se conservan intactos.
       - La sesión de usuario activa puede mantenerse.
       - La configuración general se preserva.

3.4  Actualizaciones de versión mayor (ej: v1.x a v2.x):
       - La sesión de usuario se reinicia por razones de
         seguridad y compatibilidad.
       - Los datos del negocio (pedidos, menú, empleados,
         inventario) se conservan intactos en todos los casos.
       - Pueden existir cambios en la estructura de la base
         de datos que requieran una migración automática.

3.5  Se recomienda realizar una copia de seguridad de la base
     de datos antes de instalar cualquier actualización.

3.6  Puente Prod no garantiza compatibilidad total hacia
     versiones anteriores en actualizaciones de versión mayor.

3.7  El instalador de actualizaciones desinstalará
     automáticamente la versión anterior antes de instalar la
     nueva, preservando los datos del usuario.
